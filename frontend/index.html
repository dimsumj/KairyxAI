    Mapping Sandbox

    Manual Field Mapping Use manual mapping when a connector payload needs explicit raw-path overrides before normalization. Save Mapping updates future memory, while Save and Reprocess Import reruns the selected paused import with the current editor.

    Choose a paused Awaiting Mapping import when you want the current mapping editor to reprocess that same job. Leave this empty when you only want to update future mapping memory.

    Guided Field Mapping Match each canonical field to the best raw property path. Use the per-field ? buttons for suggestions, sample values, cross-event coverage, and correction context.

    Saved Mapping Memory This section shows the currently preferred saved path for each canonical field plus any stability badges. Use the card-level ? buttons for learned-memory details, saved-history context, and alternative paths.

    Example mapping JSON 
    {
  "canonical_user_id": "event_properties.PID",
  "event_name": "event_type",
  "event_time": "event_time",
  "source_event_id": "event_properties.insert_id",
  "campaign": "event_properties.campaign_name",
  "adset": "event_properties.adgroup_name",
  "media_source": "event_properties.network"
}
    Preview Mapping and Coverage use the JSON in this editor. When a paused import is selected, the sample picker loads real raw events from that import so you can validate mappings against live source payloads.
