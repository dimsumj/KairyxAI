Help & Manual

What This Console Covers

v1 First Manual

This console is organized around the current KairyxAI v1 closed-loop stack: Data Core, Audience Engine, Action Orchestrator, Experiment Hub, and Insight Copilot. The recommended operating path is:

  1. Configure connectors and import data in Data Core.
  2. Create or refresh a cohort in Audience Engine.
  3. Bind that cohort to a workflow in Action Orchestrator.
  4. Attach an experiment and inspect results in Experiment Hub.
  5. Use Insight Copilot for query, explain, recommend, and report loops.
Current governance is role-aware. After Google login, the active organization comes from the org URL, the active project comes from the workspace selector, and permissions come from the user's memberships.

Quick Start

Hands On
  1. In Data Core → Connectors, create at least one ingest source such as Amplitude, Adjust, or AppsFlyer.
  2. In Data Core → Imports, choose a source and import a date range. If the import pauses in awaiting mapping, go to Mappings and complete the JSON mapping before retrying.
  3. Use Data Core → Churn Rescue to run churn prediction and optionally export an audience to a provider.
  4. In Audience Engine, create a cohort from SQL, a rule definition, or an explicit member list.
  5. Activate the cohort before publishing a workflow. Publish preflight will fail if the cohort is still draft or paused.
  6. In Action Orchestrator, create a workflow, test it in sandbox, then use Run Due Workflows for scheduled runs.
  7. In Experiment Hub, save experiment config, watch exposures and outcomes, then record a decision when sample and runtime thresholds are met.
  8. In Insight Copilot, run query/explain/recommend/report flows and inspect query logs, anomalies, and archived reports.

Role Guide

Safety
  • Admin: full access, no masking.
  • Analyst: read-heavy mode for experiment, copilot, and cohort metrics. Delivery payloads and PII can be masked.
  • Operator: execution-heavy mode for resume/replay, cohort activation, workflow publish/pause/resume, callbacks, and export retry.
If a request fails with `403`, switch the sidebar role to one that has permission for that operation or return to `Admin` while testing.

Common Issues

Troubleshooting
  • No processed datasets in Data Core: you probably have not completed an import or the import is blocked on mapping coverage.
  • Cohort activate or workflow publish fails: check `activation_preflight`, cohort member count, and workflow preflight requirements.
  • Deliveries or emails look masked: switch from `Analyst` or `Operator` to `Admin` if you need unmasked PII during testing.
  • Run Due Workflows returns nothing: the workflow must already be published, its scheduled hour/minute must be due, and that workflow must not have already executed for the same action date.
  • Experiment stays inconclusive: look at `sample_size`, `runtime_hours`, `srm_status`, and guardrail results in the summary panel.
  • Copilot returns insufficient evidence: seed more curated data first or use a metric that exists in the current warehouse aliases.
